# UX Sanity Checklist (Manual)

## 1) Hours Toggle Clarity

- [x] Toggle has clear two-state affordance (Money / Hours).
- [x] Toggle gives immediate tactile feedback.
- [x] Hours mode state is obvious in transactions screen via contextual banner.

## 2) Add Transaction Flow

- [x] Category selection remains clear with parent/subcategory behavior.
- [x] Form has one clear primary action (save).
- [x] Reflective hours nudge appears for expense entries when meaningful.
- [x] Save confirms with success haptic.

## 3) Wage Calculator Flow

- [x] Step progress is visible and understandable.
- [x] Navigation between steps feels lightweight and tactile.
- [x] Final save has stronger positive confirmation feedback.
- [x] True hourly value remains visually emphasized.

## 4) Dashboard/Top-Level Scanability

- [x] Bottom navigation remains focused (Transactions, Insights, Settings, Add).
- [x] No overloaded top-level action clusters.

## 5) Transaction List Readability

- [x] Rows remain compact and scannable.
- [x] Hours context is explicit in Hours mode.
- [x] Row tap opens richer detail without cluttering list UI.

## 6) Insights Understandability

- [x] Cashflow + total assets are both visible.
- [x] Period control remains easy to read.
- [x] Category breakdown remains understandable in both category and subcategory views.
